# Как ведётся работа

English: [process.md](process.md).

Доска — это память проекта. Сессия, начатая с нуля, должна прочитать
[roadmap.ru.md](roadmap.ru.md), запустить `npm run board` и понять, что делать
дальше, ни у кого не спрашивая. Всё ниже существует ради этого.

## Цикл

```
веха из дорожной карты ─> задачи с критериями приёмки ─> ветка ─> PR ─> приёмка ─> веха закрыта с числом
```

- **Веха** — milestone на GitHub, чьё название и описание повторяют заголовок в
  [roadmap.ru.md](roadmap.ru.md). Список «Приёмка» из дорожной карты — это критерий
  закрытия вехи, и разбиение на задачи его не размывает.
- **Задача** — issue, заканчивающийся блоком `## Done when`. Каждый пункт — то, на что
  команда или одно наблюдение отвечает «да» или «нет».
- **Поток** — доска `Wingspan helper`: Todo → In progress → In review → Done.
- **Замер** — [benchmarks.md](benchmarks.md), только дописывание. У каждого числа есть
  дата, размер выборки и коммит, на котором оно снято.

## Пять инвариантов

1. Нет задачи без критерия приёмки.
2. В работе одна задача. Отложенная задача помечается комментарием, а не бросается.
3. Ветка и PR на задачу; в PR — `Closes #N` и ответ на каждый пункт `Done when`.
4. `npm test && npm run check` зелёные перед каждым коммитом. Красный — это отказ,
   а не «моргнуло».
5. Число не двигается без замера, который его подвинул: Эло арены, совпадение на
   корпусе или время — в описании PR и в `benchmarks.md`.

Пятый инвариант и отличает движок, который становится сильнее, от движка, который
крутят. Эвристические веса в `src/engine/evaluate.js` — ровно тот случай, когда после
каждой правки кажется лучше, а за месяц становится хуже.

## Соглашения

- Ветка: `<слаг-вехи>-<тема>`, строчными, через дефис — `b2-power-dsl`.
- Коммит: одна строка, повелительное наклонение, область первой —
  `engine: price cached food by round`. Объясняем *почему*, если это не очевидно;
  никогда не пересказываем диф.
- Заголовок issue: повелительное наклонение, область первой, без номеров в заголовке.
- Метки: `engine`, `extension`, `ui`, `i18n`, `fixture`, `docs`, `good first issue`,
  `help wanted`. Ставим ровно те, что верны.

Тот же цикл, но с точными командами и написанный для Claude, лежит в
`.claude/skills/project-flow/SKILL.md` — Claude Code подхватывает его сам, когда
разговор заходит о вехах, задачах или доске.

## Ретро

Три строки на веху, пишутся при её закрытии: что заняло больше, чем ожидалось; что
оказалось лишним; что следующей вехе стоит сделать иначе.
