# Wingspan Helper (BGA)

[![CI](https://github.com/pagyew/wingspan-bga-helper/actions/workflows/ci.yml/badge.svg)](https://github.com/pagyew/wingspan-bga-helper/actions/workflows/ci.yml)
[![License: GPL v3](https://img.shields.io/badge/license-GPL--3.0-blue.svg)](LICENSE)

*In English: [README.md](README.md)*

Расширение для Chrome, которое читает партию в **«Крылья»** на
[Board Game Arena](https://boardgamearena.com) и говорит, какой ход принесёт
больше победных очков — и почему.

Оно читает позицию, но не играет за вас: ничего не нажимает, не перетаскивает и
не отправляет.

---

## Почему состояние читается, а не разглядывается

Скриншот планшета в «Крыльях» долго снимать и трудно разбирать: яйца — это
двенадцать пикселей, а страница успевает прокрутиться, пока вы думаете. Ничего
этого не нужно. Клиент BGA держит всю партию в JS-объектах на странице: точный
корм, точное расположение яиц, точную стоимость карт и собственный живой расчёт
мест по целям раундов. Расширение читает эти объекты напрямую.

Как до этого дошли — разбор исходников клиента и два досмотренных до конца
реплея — описано в [docs/bga-game-state.md](docs/bga-game-state.md). Документ
полезен сам по себе, если вы делаете что-то ещё для BGA.

## Состояние проекта

Ранняя стадия. Мост и чтение состояния работают, оценщик к панели ещё не
подключён. Этапы — в [docs/plan.ru.md](docs/plan.ru.md), ближайшие задачи —
в [issues](https://github.com/pagyew/wingspan-bga-helper/issues).

Что уже есть:

- мост между мирами MAIN и ISOLATED через `window.postMessage`;
- чтение состояния, сверенное на двух законченных партиях;
- оверлей-панель в shadow root: перетаскивается, сворачивается, ru / en;
- подписки на нотификации плюс heartbeat, который переживёт переименование;
- `validateState` — снимок, снятый во время анимации, отвергается, а не считается.

Модули подсчёта очков и оценки ходов были сверены до появления этого репозитория:
все шесть строк подсчёта у обоих игроков в двух реальных партиях (91 : 89 и
87 : 86). Их перенос — этап M2.

## Прежде чем ставить

Пользовательское соглашение Board Game Arena запрещает применять «устройства или
программы, отличные от предоставленных BGA», чтобы извлекать или изменять
содержимое сайта. **Расширение под это описание попадает**, хотя оно только
читает и ничего не делает само.

Понимать это стоит буквально: реплеи, соло-партии и товарищеские игры — та почва,
для которой всё и строилось. Использование в рейтинговой партии против человека —
риск для аккаунта, и это ваше решение, а не решение инструмента. В Chrome Web
Store расширение намеренно не публикуется и никогда не будет нажимать кнопки за
вас — именно эта граница отделяет помощника от бота, и по сути, и по последствиям.

## Установка

Из релиза:

1. Скачайте `wingspan-bga-helper-<версия>.zip` со страницы
   [Releases](https://github.com/pagyew/wingspan-bga-helper/releases) и распакуйте.
2. Откройте `chrome://extensions`, включите **режим разработчика**.
3. **Загрузить распакованное расширение** → выберите распакованную папку.

Нужен Chrome 111 или новее: в манифесте объявлен контент-скрипт с
`world: "MAIN"` — без него `gameui` попросту не видно.

Из исходников:

```bash
npm install
npm run build      # -> dist/
npm test
```

Дальше загрузите `dist/` как распакованное расширение.

## Как устроено

`gameui` принадлежит странице, а не расширению, поэтому контент-скрипт в
изолированном мире его не видит. Обратное тоже верно: в MAIN-мире не определён
`chrome.runtime`. Отсюда два скрипта, два мира и один мост на `postMessage`:

| Скрипт | Мир | Видит | Делает |
|---|---|---|---|
| `src/page/collector.js` | `MAIN` | `gameui`, `dojo` | читает модель, шлёт снимки |
| `src/ui/boot.js` | `ISOLATED` | `chrome.*` | считает, рисует панель, хранит настройки |

Оба стоят с `all_frames: true` — игра бывает и внутри `#gameIframe`, и
самостоятельным документом, — а панель рисует только тот фрейм, где нашёлся
`gameui`.

## Разработка

Полигон — архивные реплеи: те же объекты, что в живой партии, соперника нет,
можно перематывать. Откройте любой реплей «Крыльев» с загруженным расширением —
панель появится.

```bash
npm run watch      # пересборка на изменение
npm test           # node --test, браузер не нужен
npm run check      # проверка манифеста: миры, all_frames, match-паттерны
npm run package    # dist/ -> zip, готовый для chrome://extensions
```

Кнопка **«Снять снимок»** кладёт текущую позицию в буфер обмена как JSON. Так
живая партия превращается в тестовую фикстуру.

Кнопка **«Начать запись игры»** пишет каждый снимок всей партии и по её окончании
(состояние `gameEnd`) — или по ручной остановке — скачивает всё одним JSON-файлом:
массовая версия той же идеи, чтобы отдать целиком сыгранную партию на анализ,
а не выбирать фикстуру вручную.

## Язык

Панель следует языку страницы BGA, потому что цитирует названия кнопок самого
BGA: подсказка должна читаться как указание, которое можно выполнить. В настройках
расширения язык можно задать явно.

Issues и pull request'ы приветствуются — см. [CONTRIBUTING.md](CONTRIBUTING.md).
